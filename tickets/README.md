# Tickets

Each ticket is one file named `tickets/OPS-<number>.md`.

`sim standup` reads the `Status:` line, so keep it as a plain line at the start of the
file. A ticket counts as open until that line is exactly `Status: Done`.

## Template

```markdown
ID: OPS-<number>
Title:
Type:
Priority:
Estimate:
Status:

## Context

## Acceptance criteria

- [ ]

## Definition of done

- [ ]
```
